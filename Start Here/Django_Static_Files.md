# Django Static Files

Static files like JavaScript, CSS and images are can also be refrenced in Django the same way as HTML templates. 

The djagon.contrib.staticfiles modeule collects static files from different apps in the project. All static files should be stored in a folder called static. The folder should also be namespaced like the templates to make matching easier and precise for Django.

## Adding style.css

The following CSS code applies color green to all the listed dashboard questions.

``` 
\* polls/static/polls/style.css *\

li a {
    color: green;
}
```
To link the stylesheet in html, the following code is added at the top of the dashboard.html.
```

{% load static %}
<link rel="stylesheet" href = "{ % static 'polls/style.css' %}">
```

The {% static %} template tag generatios the absolute URL of static files.

## More Styling

To make the dashboard more appealing, a background image seems like a good initial step. 
First, an image sub directory inside the polls/static/polls folder. 
Then add the reference to the stylesheet. 

```
body {
    background: white url ( "images/background.png") no-repeat;
}
```

>>The {% static % } template tag is not available for use in static files not generated by Django such as the stylesheet. A relative path is always a good option to link the static files between each other because then the STATI_URL becomes easy to modify.
